# 안내 음성 (스캔 스테이션)

녹음 파일: `public/voice/<id>.mp3` · 재생·규칙: `src/lib/narrate.ts`

## 규칙 (무인 전시용)

- **한 번에 하나만.** 새 대사는 말하던 대사를 즉시(90 ms 페이드) 끊고 나온다 — 대기열이 없어서
  이전 씬의 말이 다음 씬으로 끌려오지 않는다. 끊긴 대사의 후속 동작은 실행되지 않는다.
- **화면은 음성을 기다리지 않는다.** 길이는 파일에서 잰 표(`CLIPS`)를 쓰므로 음소거·차단·파일 누락이어도
  진행은 똑같다.
- **첫 화면은 반복.** "안녕!…"은 끝난 뒤 15초 쉬고 다시 (`?hello=<초>`). 가까이 왔는데 작품을 안 들면
  "들어서 보여 줘!"(최대 9초마다). 상태가 0.7초 유지돼야 말하므로 인식이 깜빡여도 더듬지 않는다.
- **카운트다운은 목소리에 맞춘다.** 화면의 3·2·1이 "셋! 둘! 하나!"가 실제로 발음되는 순간에 뜬다.
- 🔈 버튼(음소거)은 효과음과 함께 음성도 끈다. `?voice=0` 음성 끔, `?voicevol=0.8` 음량.

## 대사

| id | 언제 | 대사 |
|----|------|------|
| w1_hello | 첫 화면, 아무도 가까이 없을 때 (반복) | 안녕! 채소 친구를 만들었니? 화면 앞으로 가까이 와 봐! |
| w2_show | 가까이 왔는데 작품을 안 들었을 때 / 직접 촬영 화면 | 네가 만든 채소 친구를, 들어서 화면에 보여 줘! |
| w3_still | 촬영 직전 (재촬영 포함) | 좋아! 움직이지 말고 그대로~ 사진 찍을게! |
| w4_count → w5_snap | 카운트다운 → 촬영 | 셋! 둘! 하나! → 찰칵! |
| m1_reading | 인식 중 (끝까지 말한 뒤 다음으로) | 어떤 채소 친구일까? 마법으로 알아보는 중이야~ |
| m2_noshow | 작품이 안 보일 때 | 어라? 채소 친구가 잘 안 보여! 조금만 더 가까이 보여 줄래? |
| d0_intro + d1_airplane | 미션 시작 | 이제 마법 동작 세 가지로… / 첫 번째 마법! 비행기처럼… |
| d1_cheer · d2_cheer | 1·2번 성공 (안내 중이어도 끊고 나옴) | 팔이 쑤욱! 잘했어! · 사랑을 듬뿍 주었어! |
| d2_heart · d3_stir | 2·3번 씬 시작 | 두 번째 마법!… · 마지막 마법!… |
| d3_hand | 3번에서 손이 3.5초 안 보일 때 (12초마다) | 손을 들어 봐! 국자가 손에 착 붙을 거야! |
| d_wait | 안내가 끝나고 6초간 동작이 없을 때 (씬당 1번) | 천천히 해도 괜찮아~ 마법 가루가 모이고 있어! |
| a1_alive | 냄비가 터지는 순간 → 살아났다 화면까지 이어짐 | 팡! 마법 완성! 우와~ 채소 친구가 살아났어! |
| a2_go · a3_look | 걸어 나갈 때 · 마지막 안내 | 이제 디지털 세계로 출발~! · 옆에 있는 큰 화면에서… |

## 대사 교체

같은 id로 파일을 덮어쓰고, 길이가 달라졌으면 `CLIPS`의 `skip`(앞 무음, 초)·`ms`(말하는 길이)·`gain`(음량 보정)을 고친다.

## 소리가 안 날 때

브라우저는 **사용자가 한 번 건드리기 전에는 소리를 막는다.** 첫 화면에 "🔇 안내 음성이 막혀 있어요"가 뜨면
화면을 한 번 클릭(전체화면 버튼도 됨) — 그날은 계속 나온다. 부팅 후 손대지 않고 나오게 하려면:

    open -a "Google Chrome" --args --autoplay-policy=no-user-gesture-required --kiosk "https://veggie-creature.vercel.app/"

검증: `?voicelog` → `window.__voiceLog` (말함/끊김/끝남), `window.__voicePlaying()` (지금 소리 나는 클립).
