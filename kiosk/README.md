# 원클릭 키오스크 실행

| 파일 | 용도 |
|---|---|
| 스캔PC-시작.command | Mac 스캔 PC: 절전방지 + 서버 자동기동 + 크롬 키오스크 |
| 디스플레이PC-시작.command | Mac 디스플레이 PC: 월드 화면 키오스크 |
| 윈도우-스캔PC.bat / 윈도우-디스플레이PC.bat | Windows용 동일 기능 |

- 각 파일 맨 위 `URL` 한 줄만 배포 주소로 바꾸면 됩니다.
- Mac 첫 실행 시 "확인되지 않은 개발자" 경고가 뜨면: 파일 우클릭 → 열기 (한 번만).
- 종료: Mac ⌘Q / Windows Alt+F4.
- 스캔 PC는 카메라 권한을 기억해야 하므로 시크릿 모드 없이 실행됩니다.
  첫 1회만 카메라 "허용"을 눌러주세요(이후 자동).
